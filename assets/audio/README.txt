Add your own MP3 voice recordings in this folder using these exact filenames:

bauna-intro.mp3  - Bauna Kid opening dialogue
nimbu-intro.mp3  - Nimbu Chatora opening dialogue
bauna-win.mp3    - Bauna Kid victory dialogue
nimbu-win.mp3    - Nimbu Chatora victory dialogue

The game plays the selected fighter intro first, then CPU intro, then 3-2-1-FIGHT. After the final match result, the winner voice plays. If an MP3 is missing or blocked, the game continues after a short fallback delay.
